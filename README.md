# Shopping Inventory Management System

A backend-based inventory management application built with **Node.js**, **Express**, and **MongoDB Atlas**. This project is part of the Final Project for the CCIT FTUI / Asia e University program.

## 🚀 Features
- **Inventory Tracking**: Manage products, stock levels, and categories.
- **Sales Transactions**: Process outgoing sales and link them to customers.
- **Purchase Orders**: Manage incoming stock restock via PIC.
- **Reporting**: Advanced data aggregation for sales and revenue analysis.

## 🛠️ Tech Stack
- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: MongoDB (via Mongoose ODM)
- **API Testing**: Thunder Client / Postman

## ⚙️ How to Run
1. Clone this repository.
2. Run `npm install` to install dependencies.
3. Create a `.env` file in the root directory and add your `MONGO_URI`.
4. Start the server using `node server.js`.
